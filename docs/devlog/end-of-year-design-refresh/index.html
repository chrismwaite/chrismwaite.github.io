End of year design refresh

23 November 2026

It was only the start of this year that I moved away from the previous site hosted on WordPress and NextJS and onto purely static files. Part of that move was a vast simplification of the design so that I had a simple repository of all of my content.

I'm happy I made that decision but I wanted to improve the design a little to make it easier to find interesting posts. The new design mainly switches the list-based approach to a grid-based one driven by images. I think this makes it much easier to select content to dip into. I've also collected posts that are part of the same series and there is now a feed.
